# DerpMeter app artwork

`DerpMeter.png` is the approved generated terminal-face logo, shared with the website. See `docs/brand/` for its source and creation notes.

`Providers/*.png` are 64px raster exports of the website's locally vendored Claude, OpenAI and Gemini marks (LobeHub / MIT; original license included). OpenAI is inverted for the dark surface. See `public/brands/README.md` for provenance and trademark notes.

`Fonts/` contains the website's static Geist Regular and Bold TTF faces, distributed under the included SIL OFL. See `src/app/fonts/README.md` for sources. Fonts are registered only for the lifetime of this process.

`Providers/antigravity.png` is a 64px export of Google's official transparent product mark, https://antigravity.google/assets/image/antigravity-logo.png (2026-10-22). It is a Google trademark and is not covered by the LobeHub MIT license.
